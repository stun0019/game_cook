## 原創與商用聲明

- 本批 SVG 由本專案依 `docs/ART_DIRECTION.md` 從零設計，使用通用的 2.5D、圓潤玩具造型與料理題材視覺語彙。
- 未下載、描摹、切割或嵌入任何 Pinterest 圖片，也未重製特定作品的角色、構圖、Logo、設備或圖示。
- 未嵌入外部圖片、字型或需要連線取得的資源。
- 專案方可將這些 SVG 用於本遊戲的商用版本、宣傳圖及衍生尺寸；若資產離開本專案單獨散布，應同步保留來源紀錄與版本資訊。

## 共用視覺規格

- 畫布：`viewBox="0 0 128 128"`。
- 視角：正面略偏上方的 3/4 視角。
- 外輪廓：深可可 `#54372D`，標準 4 px、圓角接合。
- 最深色：可可黑 `#35251F`，僅用於陰影及極少量深部結構。
- 色階：每項資產使用 2–3 個主要明暗層，另允許小面積高光。
- 接觸陰影：`#35251F`、18% 透明度、3 px 高斯柔化，向物件下方略偏移。
- 光源：統一來自左上；較亮面位於左上，厚度和暗面位於右下。
- 安全邊界：主體不得超出 8 px，常態建議保留 10–14 px。

## 程式整合

直接作為圖片使用：

```html
<img class="art-icon" src="assets/art/tomato.svg" alt="番茄">
```

```css
.art-icon {
  width: clamp(32px, 4.5vw, 64px);
  height: auto;
  object-fit: contain;
  filter: drop-shadow(0 3px 3px rgb(53 37 31 / 12%));
}
```

- SVG 已內建接觸陰影；外層 `drop-shadow` 僅建議用於持有物或浮動 HUD，不應套用於固定工作站。
- 縮放必須保持等比例，不得修改 `preserveAspectRatio` 或以 CSS 非等比拉伸。
- 若需選取／完成狀態，優先在外層加入光環或動畫，不直接修改 SVG 內部色票。
- 小於 28 px 顯示時應改用專用簡化版，不建議直接繼續縮小本批圖示。

## 檔名與後續擴充

- 使用全小寫 kebab-case，例如 `cooked-meat.svg`。
- 同一物件的新狀態使用語意前綴，例如 `burnt-meat.svg`、`dirty-plate.svg`。
- 新增資產時必須延續相同畫布、光源、描邊、陰影與色票，並更新本清單。
